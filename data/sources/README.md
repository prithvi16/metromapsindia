# Data sources

Hand-maintained inputs that are not produced by the build.

## `metro-master.json`

A per-system station list used only as a **name fallback** when an OSM stop has
no name and no nearby named station. It is read by
`scripts/build/normalize.ts` (`masterStationsFor`). It is not the source of map
geometry and it is not regenerated by `npm run data:build`.

The file's `metadata.sources` lists its inputs (OpenStreetMap, DMRC/HMRL/BMRCL
open feeds, Maha-Metro/CMRL/MMRDA public feeds). Update the metadata block when
the list changes. For corridor-level corrections prefer a sourced curation patch
in `scripts/curation/` instead of editing this file.
